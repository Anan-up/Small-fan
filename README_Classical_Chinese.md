# 夏日清風扇·記

此乃**純前端單頁之小戲**也，名曰「夏日清涼小風扇」，蓋自嘲消閒之玩具耳。君但啟之，即可把玩。

## 項目概覽

| 項目 | 內容 |
|------|------|
| 形態 | 單 `index.html` 一檄（約三十四千字節），無所依傍，無需營建 |
| 技術 | 原生 HTML、CSS、JS 三者而已，不假任何框架 |
| 外部資源 | 無也。音效二段（風扇嗡嗡之聲、按鍵咔噠之響）皆以 base64 內嵌其中 |
| 功能 | 風速三檔、搖頭之開關、風扇音效、暗夜模式 |

## 結構拆解

**一、純 CSS 繪扇**
- 外圈、網罩（`radial-gradient` 作同心之圓，`repeating-conic-gradient` 作放射之線）、中心之蓋，皆偽元素與漸變所畫，未嘗用一圖
- 扇葉三片，以 `border-radius: 20% 50%` 捏成葉形，各旋一百二十度而布之
- 益之以頸、以座，一台扇宛然成矣

**二、物理感動畫**
- 以 `requestAnimationFrame` 驅之，扇葉角速度依一階慣性漸趨目標：**加速也疾（τ=0.9秒），減速也徐（τ=2.2秒）**——故關機之後，扇葉慣性漸止，非驟然而停也
- 速度三檔：每秒五百四十度、七百二十度、一千三百五十度
- 搖頭者，擺幅平滑漸變（正負五度，週期四秒半）；閉搖頭時自然回正，無跳變之突兀
- 切至後台時，設 `dt` 上限於十分之一秒，防歸來時角度突跳

**三、Web Audio 音效**
- 風扇之聲製為循環音源，換檔之際，**音量與音高（playbackRate）如真電機然，指數平滑過渡**（`setTargetAtTime`）
- 音頻俟首次點擊方初始化解碼（以避瀏覽器自動播放之限），若敗則靜默降級

**四、細節考量**
- 隨系統之深色模式（CSS 變量更易黑白配色）
- 敬 `prefers-reduced-motion`：用戶若啟「減弱動態效果」，則搖頭自止
- 按鈕具 `focus-visible` 焦點之樣式、按下下沉之擬物效果，兼支持觸屏（去 tap 高亮）
