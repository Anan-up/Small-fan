# 夏日清风扇·记

此乃**纯前端单页之小戏**也，名曰「夏日清凉小风扇」，盖自嘲消闲之玩具耳。君但启之，即可把玩。

## 项目概览

| 项目 | 内容 |
|------|------|
| 形态 | 单 `index.html` 一檄（约三十四千字节），无所依傍，无需营建 |
| 技术 | 原生 HTML、CSS、JS 三者而已，不假任何框架 |
| 外部资源 | 无也。音效二段（风扇嗡嗡之声、按键咔哒之响）皆以 base64 内嵌其中 |
| 功能 | 风速三档、摇头之开关、风扇音效、暗夜模式 |

## 结构拆解

**一、纯 CSS 绘扇**
- 外圈、网罩（`radial-gradient` 作同心之圆，`repeating-conic-gradient` 作放射之线）、中心之盖，皆伪元素与渐变所画，未尝用一图
- 扇叶三片，以 `border-radius: 20% 50%` 捏成叶形，各旋一百二十度而布之
- 益之以颈、以座，一台扇宛然成矣

**二、物理感动画**
- 以 `requestAnimationFrame` 驱之，扇叶角速度依一阶惯性渐趋目标：**加速也疾（τ=0.9秒），减速也徐（τ=2.2秒）**——故关机之后，扇叶惯性渐止，非骤然而停也
- 速度三档：每秒五百四十度、七百二十度、一千三百五十度
- 摇头者，摆幅平滑渐变（正负五度，周期四秒半）；闭摇头时自然回正，无跳变之突兀
- 切至后台时，设 `dt` 上限于十分之一秒，防归来时角度突跳

**三、Web Audio 音效**
- 风扇之声制为循环音源，换挡之际，**音量与音高（playbackRate）如真电机然，指数平滑过渡**（`setTargetAtTime`）
- 音频俟首次点击方初始化解码（以避浏览器自动播放之限），若败则静默降级

**四、细节考量**
- 随系统之深色模式（CSS 变量更易黑白配色）
- 敬 `prefers-reduced-motion`：用户若启「减弱动态效果」，则摇头自止
- 按钮具 `focus-visible` 焦点之样式、按下下沉之拟物效果，兼支持触屏（去 tap 高亮）
